# ACCESS-NRI fork of the upstream Spack repository

This repository is a fork of the upstream [Spack](https://github.com/spack/spack) repository. The `access-nri` branch only contains this `README.md` file.

This repository's `access/releases/*` branches are maintained by ACCESS-NRI and allows backporting of bug fixes or important features. However, we prefer to wait for an upstream Spack bugfix release and then rebase our release branch onto the upstream release branch.

A regular user on Gadi does not need to clone this repository. Advanced users should refer to [ACCESS-NRI's Spack configuration](https://github.com/ACCESS-NRI/spack-config).
